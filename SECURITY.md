# Security policy

## Scope

This policy covers **this repository’s tooling** (`server.py`, HTML/JS lab wrappers)—not vulnerabilities in Apple iOS or third-party products described in the analysis.

## Reporting

If you find a security issue in the lab server or accidental exposure of live credentials in the repo, please:

1. **Do not** open a public issue for exploitation-ready details.
2. Contact the repository maintainer via GitHub **Private vulnerability reporting** (Security tab) or a direct message, if available.

We aim to acknowledge reports within 7 days.

## Out of scope

- Requests to improve the DarkSword exploit chain for unauthorized use.
- Vulnerabilities in patched iOS versions—report those to [Apple Product Security](https://security.apple.com/).
