# Disclaimer

This project contains **malware and exploit artifacts** associated with the DarkSword iOS exploit chain (UNC6353 / GHOSTBLADE variant), preserved for **defensive security research and education**.

## Authorized use only

You may use this repository only if you:

- Own the devices you test against, **or**
- Have **written authorization** from the device owner, **or**
- Operate an isolated lab environment (e.g. Corellium, air-gapped test hardware) explicitly designated for vulnerability research.

Using these materials to compromise systems without permission may violate computer crime laws (e.g. CFAA, analogous statutes in other countries). The authors and contributors assume **no liability** for misuse.

## What this repository is not

- Not a turnkey attack platform for use on the open internet.
- Not supported malware; C2 infrastructure from the original campaign is inactive.
- `panel.html` is a **simulation UI** with fictitious data; it does not execute the chain or contact real exfiltration endpoints.

## Reporting

If you discover a vulnerability in **this repository’s tooling** (not Apple iOS), please open a private security advisory on the hosting platform or contact the maintainer directly.

For Apple product security issues, use [Apple Security Bounty / product-security@apple.com](https://security.apple.com/).
